# YouTube LIVE 自動リロード監視(Firefox版)

指定した時間帯、対象のYouTube LIVEタブが**実際に再生を開始しているか**を定期的に確認し、まだ始まっていなければ自動でタブを前面表示&リロードするFirefox拡張機能です。配信側の開始が予定時刻より遅れる場合にも対応できます。

Edge/Chrome版と機能は同じですが、Firefoxの拡張機能API(`browser.*`)に対応させています。

## この拡張機能で解決する問題

「配信予定時刻になっても自動再生されない」原因は、多くの場合**配信者側の開始が実際には数分ずれている**ことにあります。決まった時刻に1回だけリロードしても、その時点でまだ配信が始まっていなければ意味がありません。

この拡張機能は、指定した間隔(例:1分ごと)で対象タブを繰り返しチェックし、`<video>`要素が実際に再生中かどうかを判定します。

- **まだ再生されていない** → タブを前面表示してリロードし、次のチェックへ
- **すでに再生されている** → 監視を自動的に停止し、アイコンに「LIVE」と表示

これを配信開始まで(または指定した監視時間の間)繰り返すことで、配信が実際に始まったタイミングでほぼ確実にリロードされ、自動再生が働きます。

## 機能

- 指定した日時になったら、まずタブを前面表示します
- その後、一定間隔でタブの再生状態を自動チェックします
- まだ再生されていなければ、タブを前面表示してリロード
- 再生開始を検知したら自動で監視を停止し、拡張機能アイコンに「LIVE」と表示
- 監視時間を過ぎても再生が確認できなかった場合は、アイコンに「×」と表示して終了
- 複数のタブを同時に監視可能
- 日時入力欄の「決定」ボタンでカレンダー(日時ピッカー)を閉じられます
- **Firefoxは chrome/Edge のような「30秒未満は自動的に長い間隔へ引き上げられる」仕様がないため、確認間隔を数秒単位まで短く設定できます**(目安として5秒未満にすると確認ダイアログが出ます)
- 「このタブを監視する」を押すとポップアップが自動的に閉じます
- 同じタブに対してすでに監視予定がある場合は、新規追加ではなく既存の予定を削除してから新しい予定に置き換えます(上書き)

## Firefoxへのインストール方法(一時的に試す場合)

Firefoxは、ストアに公開していない拡張機能を「一時的なアドオン」として試すことができます。ただし**Firefoxを再起動すると読み込みが解除される**点にご注意ください。

1. このフォルダ(`youtube-live-auto-reload-extension-firefox`)をパソコンの好きな場所に保存してください(ZIPを解凍した状態で使います)
2. Firefoxのアドレスバーに `about:debugging#/runtime/this-firefox` と入力してEnterを押します
3. 「一時的なアドオンを読み込む...」をクリックします
4. 解凍したフォルダの中にある `manifest.json` を選択します
5. 拡張機能が読み込まれ、ツールバーにアイコンが表示されます

## 恒久的に使いたい場合

Firefoxは、署名されていない拡張機能を通常版では恒久的にインストールできない仕様になっています。ずっと使い続けたい場合は、以下のいずれかの方法があります。

- **Firefox Developer Edition** または **Firefox Nightly** を使う(`about:config` で `xpinstall.signatures.required` を `false` にすると、署名なしでも恒久的にインストールできます)
- [Firefox Add-ons(AMO)](https://addons.mozilla.org/developers/) に開発者登録し、自己署名(Self-Distribution)で署名してもらってからインストールする

通常版のFirefoxをそのまま使う場合は、上記の「一時的なアドオン」としての利用(Firefox再起動のたびに読み込み直しが必要)が最も手軽です。

## 使い方

1. 配信の待機ページ(YouTube LIVEの視聴予定URL)を開いた状態で、拡張機能のアイコンをクリックします
2. 「前面表示&監視を開始する日時」に、配信予定時刻の少し前(例:1〜2分前)を設定し、必要なら「決定」ボタンでカレンダーを閉じます
3. 「確認間隔」で、どのくらいの間隔でチェックするかを設定します。単位は「秒」「分」から選べます(デフォルト60秒)
4. 「監視を続ける時間」で、最大どのくらいの時間監視を続けるかを設定します。こちらも単位は「秒」「分」から選べます(デフォルト30分)
5. 「このタブを監視する」をクリックします

指定した日時になると、まずそのタブが前面表示されます。まだ配信が始まっていなければ、以降は指定した間隔でリロード&前面表示を繰り返し、再生が始まったことを検知すると自動的に停止します。拡張機能アイコンのバッジで状態を確認できます(残り回数の数字 → 検知したら緑の「LIVE」 → 時間切れなら赤の「×」)。

## 注意点

- 対象タブが**前面表示**されるため、指定した確認タイミングごとに、作業中の他のウィンドウから強制的に切り替わります
- 確認間隔を短くしすぎる(例:数秒おき)と、頻繁に画面が切り替わって作業の妨げになります。用途に応じて調整してください
- Firefoxはchrome/Edgeのような「短い間隔は自動的に引き上げられる」仕様がないため、5秒未満の間隔も設定できます(その場合は確認ダイアログが出ます)。ただし極端に短い値は動作が不安定になる可能性があります
- パソコンがスリープしている、またはFirefoxが完全に終了している間は動作しません
- 「一時的なアドオン」として読み込んだ場合、Firefoxを再起動すると拡張機能が消えるため、再度読み込みが必要です
- タブを閉じていた場合は、記録していたURLで自動的に開き直します
- 再生判定は「`<video>`要素が実際に再生されているか」で行っています。YouTube側のページ構造が変わると、判定がうまく働かなくなる可能性があります
